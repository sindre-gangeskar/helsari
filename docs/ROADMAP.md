# Roadmap

## In progress

- **Restructure** the code into `runtime/`, `libs/` and `port/`, so everything game-specific is in one place.

## Next

1. **Direct3D 12**, replacing Direct3D 11, so upscalers can be added: FSR 3.1 and later, XeSS and DLSS.
2. **The 1.29 update**: Helsari now runs 1.29, the game's last update; check every feature on it.
3. **An installer** that builds the game on the player's PC, step by step, from their own files.
4. **A native menu cursor**, highlighting menu rows directly and not through simulated key presses.
5. **Higher framerates in the busiest scenes**, where the CPU side limits the game to about 50 fps.
6. **Remaining rendering differences** from the PS3.
